# Clinical Pharmacokinetics Learning Lab

Interactive tools that make precision dosing concepts easier to visualize. Built by a pharmacist to make clinical software logic transparent and intuitive.

**Live Site:** [yinaxu.github.io/PK_Project](https://yinaxu.github.io/PK_Project)

---

## The Problem

Precision dosing software for vancomycin, aminoglycosides, and AUC monitoring is becoming standard in hospital pharmacy. However, the math behind it (population PK models, MAP estimation, and Bayesian posteriors) often feels like a black box to the clinicians using it day to day.

Pharmacists are frequently asked to trust the numbers generated by software without a clear visual sense of why a recommendation changed between two patient drug levels, or how a Bayesian estimate differs from a standard population-based model.

This project makes that logic transparent. It translates precision dosing concepts into interactive visual tools that clinicians can explore, teach, and explain in practice.

## Interactive Tools

Each tool focuses on clear equations, real-time visual feedback, and plain-language explanation rather than automated black-box calculations.

| Tool | File | What It Does |
| :--- | :--- | :--- |
| **Bayesian Vancomycin Explorer** | `vancomycin-explorer.html` | Displays a basic population PK prediction next to a Bayesian posterior updated by an observed drug level, showing visually how a measured level shifts the curve. |
| **Extended-Interval Aminoglycoside Explorer** | `aminoglycoside-explorer.html` | Recommends an initial dosing interval based on renal function, then plots levels against target-trough boundary curves with plain-language clinical interpretations. |
| **Clinical Case Explorer** | `case-explorer.html` | Walks through a complete patient case (initial regimen, two sequential levels, and changing renal function) with a narrative explaining why the estimates and recommendations change over time. |

## Model Notes and Limitations

These tools are simplified models built for educational and demonstration purposes. They are not intended or validated for actual clinical decision-making.

* **Simplified Models:** The tools use single-parameter or population-average approximations rather than the multi-compartment statistical models used in commercial clinical software.
* **Nomogram Approximations:** The aminoglycoside boundary curves reflect target-trough concepts inspired by the Hartford nomogram, but they are simplified approximations rather than exact chart reproductions.
* **Teaching Logic:** Sequential updates in the Case Explorer use simplified rules to demonstrate how changing serum creatinine alters estimates, rather than a validated sequential Bayesian algorithm.
